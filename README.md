# About me:
I'm a Software/Platform Engineer working on data and research infrastructure. Day to day that means Python (polars, PyArrow/ADBC, Pydantic) and SQL (PostgreSQL/DuckDB), building correctness-critical data pipelines, lakehouse/medallion architectures, and the observability layer that tells us when something's actually wrong before a researcher finds a silently-wrong number first.

I own our observability/reliability stack end-to-end (Sentry integration, alerting, MTTR tracking), and I'm the one people come to for performance work: memory profiling, cutting query/pipeline runtime, and making large data operations actually scale. Before this I spent a few years as a Data Engineering Tech Lead, leading a team and building ETL platforms and automation tools in Python and .NET.

When I'm not working, you'll find me tinkering with code in more novel settings (currently building a custom clock), playing soulslikes, or practicing classical guitar.
